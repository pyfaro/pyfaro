# Tested versions

Pyfaro's integration tests and the projects generated by `pyfaro create` use
these versions:

| Tool | Version | Role |
| --- | --- | --- |
| [uv](https://docs.astral.sh/uv/) | 0.9.26 | Dependencies, environments, Python |
| [Ruff](https://docs.astral.sh/ruff/) | 0.16.10 | `lint`, `fmt`, `check` |
| [ty](https://docs.astral.sh/ty/) | 0.0.85 | `type`, `check` |
| [pytest](https://docs.pytest.org/) | 9.1.1 | `test` |

!!! info "Minimum versus tested"
    - **uv 0.9.26 or newer** is required. Older versions are rejected and
      newer stable versions are accepted, though not claimed as tested.
    - Ruff, ty and pytest are not rejected for being a different version. They
      only need to report a parseable version. Other versions may work, but
      only the ones above are tested.

Generated `pyproject.toml` files pin Ruff, ty and pytest to the versions above
in the `dev` dependency group, and require `uv_build>=0.9.26,<0.10.0`.

Also relevant: building Pyfaro from source needs Rust 1.90 or newer.

To see what Pyfaro finds on your machine, run
[`pyfaro tools`](../commands/tools.md) or [`pyfaro doctor`](../commands/doctor.md).
For supported operating systems, see [Platform support](../concepts/platform-support.md).
