# Changelog

Pyfaro keeps a single changelog at the root of the repository and publishes
each release on GitHub.

- [`CHANGELOG.md`](https://github.com/pyfaro/pyfaro/blob/main/CHANGELOG.md) lists every change, release by release.
- [GitHub Releases](https://github.com/pyfaro/pyfaro/releases) offers the downloadable archives and `SHA256SUMS` for each version.
- [crates.io](https://crates.io/crates/pyfaro) hosts the published crate.

## Releases at a glance

| Version | Date | Highlights |
| --- | --- | --- |
| `0.5.0-beta.1` | 2026-10-25 | `build`, shell completions, `--verbose`, install scripts, PyPI wheels, build provenance attestations |

| `0.1.0-alpha.1` | 2026-10-19 | First release: `init` |

Nothing is in development yet beyond `main`.

!!! note
